## 🟢 SYSTEM OVERVIEW

**Exavi File** is a next-generation file infrastructure offering secure storage, semantic search, and AI-ready access for modern workflows and autonomous systems. 

Unlike traditional cloud storage which acts as a passive locker, Exavi creates an **active data layer**. Files uploaded to Exavi are indexed by vector databases, allowing AI agents to understand, query, and utilize the content securely via smart contract permissions.

### ⚡ Core Utilities

| Feature | Description |
| :--- | :--- |
| **Intelligent Storage** | Store files with built-in metadata, versioning, and semantic indexing. |
| **AI-Ready Access** | Files can be queried, summarized, and analyzed directly by AI agents. |
| **Semantic Search** | Find files by *meaning*, not just filenames (e.g., "Show me the contract about rent"). |
| **Smart Sync** | Real-time syncing with granular permissions for users, teams, and agents. |

## 🚀 INSTALLATION & LOCAL DEVELOPMENT

Follow these steps to deploy the node locally.

### Prerequisites
*   Node.js v18+
*   npm or yarn

### 1. Clone the Repository
```bash
git clone https://github.com/yourusername/exavi-file.git
cd exavi-file
```

### 2. Install Dependencies
```bash
npm install
# or
yarn install
```

### 3. Initialize Dev Server
```bash
npm run dev
```
Access the interface at `http://localhost:5173`
